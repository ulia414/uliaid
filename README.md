# Personal Branding Web App

Aplikasi web sederhana berbasis Kotlin yang menampilkan landing page personal branding.

## Menjalankan

```bash
./gradlew run
```

Buka `http://localhost:8080`.

## Kustomisasi

Ubah data default pada fungsi `PersonalBrandingProfile.default()` di:

- `src/main/kotlin/com/uliaid/personalbranding/Main.kt`

## Testing

```bash
./gradlew test
```
